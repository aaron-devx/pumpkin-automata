Why
DFA & NFA?

Both accept regular languages. A DFA has one next state. An NFA may branch — accept if any path ends in F.

How to read the trace
01

DFA

One next state for each state and symbol. The string takes one path, then accepts or rejects at the end. Like a road sign: “Turn Right” is one instruction.

02

NFA

May have 0, 1, or many next states, and may use ε. Accepts if at least one path ends in an accept state.

03

Same power

Every NFA has an equivalent DFA. Both recognize the same languages.

DFA vs NFA
PropertyDFANFA

Free moves (ε)NoYes
