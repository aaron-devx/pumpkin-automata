Why
DFA & NFA?

Both accept regular languages. A DFA has one next state. An NFA may branch — accept if any path ends in F.

See the 3 steps
01

Deterministic

One symbol, one move. Easy to trace — what Week 7 calls a DFA.

02

Nondeterministic

Zero, one, or many moves. Accept if some branch reaches an accepting state.

03

Same power

Every NFA has an equivalent DFA. This lab shows the walk, not the conversion proof.
